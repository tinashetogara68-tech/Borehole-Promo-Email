# Solar Installation Marketing Email

## Overview

A promotional HTML email template developed for a solar installation company to showcase its off-grid solar solutions. The email uses a structured table-based layout to present company branding, solar installation imagery, product benefits, pricing information and contact details in a visually organised format.

The project demonstrates the use of HTML and inline CSS to create a marketing email with interactive elements and externally hosted images.

## Features

### 1. Company Branding
- Displays the company's logo and business information.
- Includes the company's website as a clickable hyperlink.
- Presents the company's service area and solar installation offering.

### 2. Promotional Content
- Features a large solar installation image.
- Highlights key benefits of solar energy, including potential electricity bill savings and reduced carbon emissions.
- Includes promotional pricing information for available packages.

### 3. Interactive Contact Information
- Includes a clickable telephone and WhatsApp contact link.
- Provides a direct link to the company's website.
- Includes an email mailing-list removal instruction.

### 4. Email Layout and Styling
- Uses HTML tables to structure the email content.
- Implements inline CSS for styling and layout.
- Incorporates externally hosted images and icons.
- Includes viewport metadata for mobile device compatibility.

## Technologies Used

- **HTML5:** Email content structure and layout.
- **CSS:** Inline styling, typography, colours, spacing and presentation.
- **HTML Tables:** Structured email layout.
- **Hyperlinks:** Website navigation and WhatsApp contact integration.

## Project Purpose

This project was developed as a practical exercise in creating a promotional email for a real-world business context. It demonstrates the application of web development fundamentals to business communication and digital marketing.
